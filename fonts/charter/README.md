# Bitstream Charter webfonts

Original Bitstream Charter, converted to WOFF2 and distributed by Matthew Butterick.

Source: https://practicaltypography.com/charter.html

Archive: https://practicaltypography.com/fonts/Charter%20210112.zip

The four WOFF2 files and `Charter license.txt` are copied unchanged from that archive. The website serves the fonts locally and declares their Regular (400), Bold (700), Italic (400), and Bold Italic (700) faces in `style.css`.
